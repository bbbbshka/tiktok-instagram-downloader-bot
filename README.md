# TikTok & Instagram Video Downloader Bot

Telegram-бот для быстрого скачивания видео и фото из TikTok и Instagram. Работает в личных сообщениях и в **inline-режиме** прямо в любом чате.

## Возможности

- 🎬 **Скачивание видео** — отправьте ссылку TikTok или Instagram → получите видео в чат
- 📸 **Фото из TikTok** — поддержка карусели/слайдшоу (несколько фото альбомом)
- 🔗 **Inline-режим** — напишите `@имя_бота <ссылка>` в любом чате
- 🎵 **Скачивание музыки** — кнопка "Музыка" скачает аудио-трек из видео
- 💬 **Комментарии** — кнопка "Комменты" покажет топ комментариев
- ❤️ **Статистика** — лайки, просмотры, количество комментариев под видео
- ⚡ **Быстрая загрузка** — параллельные фрагменты, кеш file_id, 720p
- 🌐 **Мультиязычность** — русский и английский

### Как это выглядит

Когда отправляешь ссылку, бот присылает видео/фото с подписью:
```
@username
Текст описания видео
❤️ 15.2K  👁 1.2M  💬 342
```

И кнопки:
```
[❤️ 15.2K] [💬 342 комментов]
[🔗 Ссылка] [🎵 Музыка]
```

Для фото-каруселей — кнопки навигации `◀️ 1/5 ▶️`.

### Поддерживаемые платформы

| Платформа | Форматы ссылок |
|-----------|----------------|
| TikTok | `tiktok.com`, `vm.tiktok.com`, `vt.tiktok.com`, `m.tiktok.com` |
| Instagram | Reels, посты (`/p/`), IGTV (`/tv/`), Stories |

## Установка

### 1. Клонирование
```bash
git clone https://github.com/bbbbshka/tiktok-instagram-downloader-bot.git
cd tiktok-instagram-downloader-bot
```

### 2. Зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройка
```bash
cp .env.example .env
```

Заполните `.env`:
- `BOT_TOKEN` — токен от @BotFather
- `SUPER_ADMIN_ID` — ваш Telegram ID (от @userinfobot)

### 4. Включите inline-режим
В @BotFather:
1. `/mybots` → выберите бота
2. **Bot Settings** → **Inline Mode** → **Turn on**

### 5. Запуск
```bash
python bot.py
```

## Оптимизация скорости

- **Параллельные фрагменты** — yt-dlp скачивает до 8 фрагментов одновременно
- **720p формат** — быстрее чем 1080p, при этом хорошее качество
- **Кеш file_id** — повторная отправка видео мгновенна
- **Без пост-обработки** — mp4 отправляется как есть

## Переменные окружения

| Переменная | Обязательная | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен Telegram бота |
| `SUPER_ADMIN_ID` | нет | Telegram ID администратора |
| `MAX_VIDEO_SIZE` | нет | Макс. размер видео (по умолчанию 50 МБ) |
| `CONCURRENT_FRAGMENTS` | нет | Параллельные загрузки (по умолчанию 8) |
| `CACHE_TTL_SECONDS` | нет | TTL кеша file_id (по умолчанию 3600 сек) |
